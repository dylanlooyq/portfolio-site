Claude Switcher

A lightweight tool for switching between Claude accounts and API connectors. It switches Claude Code between your claude.ai logins and LLM gateways without hand-editing settings.json.

I'm actively looking for feedback and collaborators. If you use Claude across several accounts or connectors, I'd like to hear what would make this more useful, and I'm open to contributions.
